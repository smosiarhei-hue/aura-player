# AutoMix DSP — офлайн-движок DJ-сведения

Готовый, полностью нативный модуль (SwiftUI 6 / Swift 6 strict concurrency,
iOS 26+, проверен под iOS 27). Работает **на устройстве, офлайн**: ни один
шаг анализа, выбора трека или расчёта сведения не требует сети. Яндекс
API используется только для подбора «волны» (ротор `user:onyourwave` и
похожие треки) — сам микс считается локально.

## Конвейер

```
Трек (локальный файл / закэшированный стрим Яндекса)
   │
   ▼  AVAssetReader → mono 22.05 kHz, один проход (streaming, без загрузки в RAM)
AutoMixDSP.features  ── spectral flux (onsets), RMS-кривая, chroma, vocal-ratio
   │
   ├─ BeatAnalyzer      → BPM (автокорреляция onset-огибающей), сетка битов,
   │                       даунбиты, уверенность
   ├─ KeyDetector       → тональность (Krumhansl–Schmuckler по chroma)
   ├─ StructureAnalyzer → интро/аутро, дропы, билд-апы, вокал/инструментал,
   │                       тишина, кривая энергии
   ▼
TrackAnalysis (кэш на диске, ключ = версия алгоритма + ID файла/трека)
   │
   ▼  за ~65 c до конца трека
TransitionPlanner.planLocalFallback  (чистая функция, 0 мс, офлайн)
   │  • ритм-скор (BPM ±6% окно стретча, половинные/двойные темпы)
   │  • гармония (Camelot wheel)
   │  • энергия/танцевальность (не прыгать с баллады на бэнгер)
   │  • вокальные коллизии (не накладывать два вокала)
   │  • стратегия: BASS_SWAP / BEAT_MATCH_EQ / FILTER_TRANSITION /
   │    ENERGY_BLEND / ECHO_OUT / VOCAL_CUT / SILENCE_TRIM / HARD_CUT …
   │  • cue — прибит к даунбиту, длинна бленда — в целых тактах
   ▼
BeatgridSync.arm  (sample-accurate планировщик)
   │  • входящий дек планируется НА БУДУЩЕЕ (AVAudioTime/hostTime):
   │    его первый даунбит рендерится в тот же сэмпл, что и cue-даунбит
   │    уходящего трека
   │  • оба TimePitch запираются на постоянные рейты темп-лока
   │    (общий wall-clock период бита, расхождение < 2%)
   │  • позиция считается с render-часов (playerTime), не с настенных часов
   ▼
Cue watcher (60 Гц) → в момент cue стартует рампа
   │
   ▼  30 Гц, только громкость/EQ/reverb — рейты НЕ трогаются (сетки не плывут)
tickTransition: equal-power кроссфейд, bass-swap, фильтр-свип, reverb-хвост
   │
   ▼
completeTransition: дек меняются местами, якоря/рейты сбрасываются,
плеер доезжает до unity (release ramp), следующий план уже в работе
```

## Ключевые файлы

| Файл | Ответственность |
|---|---|
| `AutoMix/BeatgridSync.swift` | Sample-accurate арм: расчёт задержки, кадры входа, render-clock позиция |
| `AutoMix/AutoMixDSP.swift` | Один streaming-проход: onset/RMS/chroma/vocal (vDSP FFT) |
| `AutoMix/BeatAnalyzer.swift` | BPM, сетка битов, даунбиты |
| `AutoMix/KeyDetector.swift` + `CamelotWheel.swift` | Тональность и гармоническая совместимость |
| `AutoMix/StructureAnalyzer.swift` | Секции, дропы, вокал, тишина, энергия |
| `AutoMix/TrackAnalysis.swift` | Модель анализа + кэшируемый JSON |
| `AutoMix/TrackAnalysisService.swift` | Actor-оркестратор: диск/память/анализ, стримы анализируются по эконом-копии |
| `AutoMix/TransitionPlanner.swift` | Офлайн-планировщик: скоринг, стратегия, cue, огибающие эффектов |
| `AutoMix/SmartNextTrackSelector.swift` | Выбор следующего трека по вайбу: гармония 42% / ритм 33% / энергия 20% / уверенность 5% |
| `AutoMix/MoodRadioEngine.swift` | «Моя волна»: ротор Яндекса + локальное ранжирование по вектору настроения |
| `playercore.swift` | Два дека (playerA/playerB), TimePitch, 10-полосный EQ, reverb, лимитер, арм/рампа |
| `AutoMixHUD.swift` | Индикатор BEAT LOCK, BPM, стратегия, % совпадения следующего трека |

## Как это ощущается

- **Beat-lock**: следующий трек входит ровно на долю — слышно, как две
  драм-машины складываются в одну. В HUD пульсирует зелёная точка «BEAT LOCK».
- **BPM подтягивается плавно** (pre-lock за ~8 c до cue), без рывка питча
  (TimePitch меняет темп, тон остаётся).
- **Bass-swap**: низ уходящего трека убирается перед входом входящего —
  нет гулкого наложения баса.
- **Фильтр-свип и reverb-хвост** на энергичных переходах, echo-out на концах.
- **Процент совпадения** следующего трека показывается заранее: похожий
  вайб/жанр/BPM/тональность подбираются и офлайн (локальная библиотека +
  скачанное), и онлайн (ротор Яндекса).

## Настройки

- Режим перехода: **AutoMix (DJ-сведение)** / Кроссфейд / Gapless / Выкл.
- «Облачный AI-план переходов» — **выключен по умолчанию**: всё считается
  локально. Включение добавляет облачный планировщик, офлайн-движок
  остаётся фолбэком (с circuit breaker на блокировки региона).

## Потоковые треки Яндекса

Стримы воспроизводятся через AVPlayer (два плеера для кроссфейда). Их анализ
также делается офлайн: сервис один раз скачивает эконом-копию, декодирует и
удаляет — остаётся только JSON анализа. Для локальных файлов сведение
sample-accurate; для стримов — темп-лок плюс запуск на грани cue (джиттер ≤ 33 мс).
