# AutoMix V2 — приёмка этапа 2

## Автоматические критерии

- TrackAnalysis и MixPlanner собираются в Swift 6 strict concurrency.
- Синтетические click-треки 90/120/128/174 BPM: ошибка не больше 1 BPM.
- Проверяются `.none`, `.crossfade`, album-gapless, короткие треки, cue-точки и LUFS gain offset.
- Весь набор unit-тестов этапов 1–2 должен пройти.

## Проверка на реальных треках

Подготовить 30 полностью скачанных треков: электронная музыка, поп, рок, live, ambient, треки с fade-out и тишиной в конце.

Для каждого трека открыть **Настройки → AutoMix V2 → Диагностика** и записать:

| 2 | | | | | | | | | | |
| 3 | | | | | | | | | | |

Продолжить таблицу до 30 строк.

## Критерии принятия

- не меньше 27 из 30 треков имеют разумный BPM или помечены низкой confidence;
- AutoMix не считает немиксуемый трек надёжно миксуемым;
- `mixInSec` не попадает в тишину;
- `mixOutSec` не обрезает заметный конец;
- повторный анализ загружает JSON-профиль без повторного декодирования;
- смена текущего трека отменяет устаревшую задачу анализа;
- анализ не прерывает воспроизведение и выполняется с utility priority.

Ручная 30-трековая проверка требует реальных аудиофайлов на устройстве и не может быть подтверждена GitHub Actions.
