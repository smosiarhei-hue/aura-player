# Sonivo · Threads promo kit

Карусель и текст для рекламного поста в **Threads** (также подойдёт IG carousel / X media).

## Быстрый старт

```bash
cd marketing/threads-promo
python3 -m http.server 8765
# открой http://127.0.0.1:8765
```

Карточки **1080×1350** (Threads / IG portrait). Сделай скрин каждой карточки или экспортируй через DevTools → Capture node screenshot.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Живой preview + готовый текст треда |
| `cards/00-type.jpg` | Типографический cover |
| `cards/01-hero.jpg` | Hero с телефоном |
| `screens/*.png` | Сюда кладёшь реальные скрины приложения |

## Референсы типографики

- [Mendiak/plaintext](https://github.com/Mendiak/plaintext) — Swiss editorial posters
- [op7418/guizang-social-card-skill](https://github.com/op7418/guizang-social-card-skill) — 28 editorial/Swiss layouts → PNG
- [joeseesun/qiaomu-info-card-designer](https://github.com/joeseesun/qiaomu-info-card-designer) — magazine cards for X
- [capsrock/bauhaus-design-skill](https://github.com/capsrock/bauhaus-design-skill) — Bauhaus / Swiss grid
- Threads language: black type, white air — [Curio](https://designbycurio.com/threads-meta-2023)

## Что нужно от владельца

1. Реальные скрины iPhone (Now Playing, AutoMix MIXING, Моя волна, EQ, опц. Lyrics).
2. Ссылка CTA (TestFlight / сайт / DM).
3. Ник `@` в Threads.
4. Положить PNG в `screens/` → попросить агента «вставь скрины».
