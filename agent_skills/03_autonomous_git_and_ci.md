# 🛠️ Autonomous Git, XcodeGen & CI/CD Skill

## Протокол работы автономного агента:
1. **Анализ перед изменением**:
   - Никогда не догадывайся о структуре кода! Сначала используй search_code или 
ead_file.
   - Читай файл вокруг места изменения, чтобы не нарушить сигнатуры и импорты.

2. **Точечное и безопасное редактирование**:
   - Используй dit_file с точным совпадением контекста (3-5 строк вокруг).
   - Проверяй уникальность заменяемого фрагмента.

3. **Коммит и доставка в GitHub**:
   - После успешных правок делай git_commit_and_push с понятным описанием по Conventional Commits (eat:, ix:, 
efactor:).
   - Если сборка упала, используй get_failed_build_logs, найди точную ошибку компилятора Xcode и мгновенно исправь её!
